# 모모의 작은 정원

치즈냥이와 함께 쉬어가는, 한국어로 된 반응형 정원 시뮬레이션입니다. React와 Vite로 만들었으며 서버나 API 키가 필요하지 않습니다. 그림·날씨·고양이 동작은 SVG와 CSS로 구현했고, 서체는 앱에 포함했습니다.

Codex의 파일 링크는 소스 코드 보기로 열릴 수 있습니다. HTML 파일을 눌렀을 때 코드가 보이는 것은 웹사이트 실행 결과가 아닙니다. 클라우드 환경의 Publish는 개발 환경을 보존하는 기능이며 웹사이트를 공개하는 배포 과정과 별개입니다.

## 실행

Node.js 22 이상과 npm을 사용합니다. 검증 환경은 Node.js 24입니다.

```sh
npm ci --cache /tmp/sunny-npm-cache --no-audit --no-fund
npm run dev
```

개발 서버는 `0.0.0.0:3000`에서 실행됩니다.

## HTML 파일로 바로 열기

저장소 루트의 `index.html`은 Vite 개발용 진입 파일이므로 파일 미리보기나 더블클릭으로 실행하지 않습니다. 서버 없이 실행할 때는 다음 명령으로 단일 파일을 만드세요.

```sh
npm run build:standalone
```

생성된 `standalone/momo-garden.html`을 내려받아 Chrome, Edge, Safari 등의 브라우저에서 여세요. JavaScript·CSS·한국어 폰트·그림이 모두 포함되어 다른 파일이나 인터넷 연결 없이 실행됩니다. 채팅의 파일 미리보기는 JavaScript 실행을 제한할 수 있으므로, 미리보기에서 오류가 나면 파일을 내려받아 브라우저로 열어주세요. 이 파일에서는 브라우저가 파일의 저장 공간 접근을 허용할 때 상태가 저장됩니다.

```sh
npm run build
npm run preview -- --port 3000
```

`dist/`를 정적 호스팅에 배포할 수 있습니다. 폰트를 포함한 실행 자산이 로컬로 번들되며, 외부 이미지·폰트 서버에 의존하지 않습니다.

## 일반 웹주소로 배포하기

`.github/workflows/deploy-pages.yml`에 `kingpeum/sunny`용 GitHub Pages 배포 구성을 준비했습니다. 공개 웹사이트가 생성되므로 소유자의 배포 승인을 받은 뒤 진행합니다. 현재 이 파일을 준비한 것만으로는 업로드·배포·공개가 이루어지지 않습니다.

1. 승인 후 소스 코드를 GitHub 저장소의 기본 브랜치에 올립니다.
2. 저장소의 Settings → Pages → Build and deployment에서 Source를 GitHub Actions로 설정합니다. 계정·저장소 유형에 따라 GitHub Pages 사용 가능 여부를 확인합니다.
3. Actions → Publish Little Garden → Run workflow를 실행합니다. 코드 업로드만으로는 이 워크플로가 실행되지 않습니다.
4. 배포 작업이 성공한 뒤 작업 결과의 실제 페이지 주소를 열어 화면과 상호작용을 확인합니다. 성공 전에는 접속 가능한 사이트가 생겼다고 판단하지 않습니다.

이 워크플로는 `/sunny/` 하위 경로용으로 빌드합니다. 다른 저장소명이나 사용자 도메인을 사용하면 배포 경로도 맞춰야 합니다.

## 함께하는 방법

- 고양이가 정원을 자유롭게 산책하고 낮잠, 나비 잡기, 풀 냄새 맡기, 그루밍, 기지개, 앞발 핥기를 번갈아 합니다.
- 정원 속 머리 또는 등을 클릭하거나 아래의 쓰다듬기 버튼을 누르면 서로 다른 자세로 반응하고 행복·친밀도가 올라갑니다. 고양이의 두 터치 영역은 키보드 Tab과 Enter/Space로도 조작할 수 있습니다.
- 맑음·흐림·비·눈을 고르세요. 자동 변화를 켜면 1분마다 날씨가 바뀝니다.
- 일시정지, 정원 전체화면, 자연의 소리 기능을 제공합니다. 소리는 버튼을 눌러야 재생됩니다.
- 고양이 이름 옆 연필로 이름을 바꾸고, 하루 세 번 간식을 줄 수 있습니다.
- ‘고양이의 하루 들여다보기’에서 여섯 가지 행동을 직접 선택할 수도 있습니다.
- 오늘의 이름·행복·에너지·친밀도·손길 횟수·간식 사용량은 브라우저 localStorage에 저장됩니다. 날짜가 바뀌면 초기화되며, 일기 목록은 현재 세션의 기록입니다. 계정·서버 동기화는 없습니다.

## 구조

- `src/useGarden.js`: 이동, 행동 선택, 시뮬레이션 시계, 날씨, 상호작용 및 상태 저장
- `src/components/GardenArt.jsx`: 정원 일러스트
- `src/components/Cat.jsx`, `Cat.css`: 치즈냥이 포즈·애니메이션·머리/등 터치 영역
- `src/components/GardenScene.jsx`: 고양이 배치, 나비, 강수 효과 및 정원 제어
- `src/App.jsx`: 화면, 프로필, 일기, 안내, 행동 선택 및 소리

## 확인 항목

빌드 외에 Chromium에서 날씨 네 가지, 머리/등 반응, 행동 여섯 가지, 간식 제한, 상태 복원, 일시정지, 모달과 모바일 화면을 검증합니다. 설정을 변경할 때에도 실제 브라우저에서 고양이 상태와 상호작용 결과를 함께 확인하세요.
